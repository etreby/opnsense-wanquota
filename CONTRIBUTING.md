# Contributing

Please open an issue before a large change. Never attach a production
`config.xml`, traffic database, packet capture, public IP address, credential,
or device inventory. Use documentation-only addresses and synthetic fixtures.

Contributions use the BSD-2-Clause license. Run `make test` before submitting.

## AI disclosure

The initial implementation and public-release hardening were developed with
OpenAI Codex (GPT-5 family) under human review. Contributors must disclose
material AI assistance in their pull request, as required by OPNsense.
