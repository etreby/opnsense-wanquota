What a block actually does
  1. block in on LAN from <wanquota_blocked> to !<LAN net>, first in the LAN rule list.
  2. Internet access stops. LAN-to-LAN traffic is untouched, so a printer or a NAS still answers.
  3. DNS and NTP served by the firewall keep working, because its own address is inside the LAN network — a blocked device does not also lose its clock.
  4. First in the list on purpose: appended, it showed Evaluations: 0 while the blocked device browsed normally, because a broad LAN allow rule is a pf quick rule and matched first.

A quota is a calendar-month allowance: a device's traffic is split across both links by the load balancer, so there is no single billing cycle it belongs to. The firewall itself, devices marked excluded, and members of a protected infrastructure group can never be blocked — each refusal is reported on its own row rather than dropped.
