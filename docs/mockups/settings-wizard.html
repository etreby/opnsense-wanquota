WAN providers

One entry per internet connection, with its allowance and billing day. Providers 3 and 4 are off by default.

ETISALAT
Display name, usually the ISP. Appears in every report and alert.
wan
OPNsense logical interface, not the device name, so reassigning hardware does not break accounting.
140
Monthly allowance in decimal GB, as the ISP states it.
1
Day of the month the allowance resets. Caps that reset mid-month are common.
0
Usage already consumed this cycle before the plugin could measure it. Added to the measured total, which closes the gap when vnStat has no history for part of the cycle.
